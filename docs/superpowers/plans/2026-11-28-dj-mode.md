# DJ Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Appy plays, searches, queues and controls music in Riff by voice, ducks it while anyone talks, and survives the laptop mic hearing the music until the ReSpeaker arrives.

**Architecture:** `riff.py` talks MPRIS to Riff over the session bus (transport, volume, now playing, launch). `spotify.py` talks to the Spotify Web API as Tudor (PKCE login, search, play on Riff's Connect device, queue, playlists, liked songs). `dj.py` combines them into the two LLM tools plus the ducker and the card payload; `tools.py`/`main.py` wire them in like weather and memory. A flag-gated, tagged `hearing_workaround.py` holds the temporary bits.

**Tech Stack:** Python 3 (`httpx`, new dep `jeepney`), `unittest`; Rust GTK4 overlay (`appy-ui`); PipeWire `libpipewire-module-echo-cancel`.

**Spec:** `docs/superpowers/specs/2026-11-28-dj-mode-design.md`

## Global Constraints

- Work in `/home/tudor/dev/appy-dj` (branch `feat/dj-mode`). Python is the main checkout's venv: `PY=/home/tudor/dev/appy/.venv/bin/python`. Full suite: `$PY -m unittest discover -s tests -t .` and `cd appy-ui && cargo test`.
- Riff bus name `org.mpris.MediaPlayer2.dev.diegovsky.Riff`, path `/org/mpris/MediaPlayer2`, interface `org.mpris.MediaPlayer2.Player`. Launch: `flatpak run dev.diegovsky.Riff`.
- Redirect URI `http://127.0.0.1:8898/callback`. Env `SPOTIFY_CLIENT_ID`. Token file `~/.config/appy/spotify.json`, mode 0600. Scopes exactly: `user-read-playback-state user-modify-playback-state user-read-currently-playing playlist-read-private user-library-read`.
- No Spotify token, code or client ID in logs, tool results, or the repo. Tool results never contain URIs or IDs.
- Transport (`music_control`) uses MPRIS only, never the Web API.
- Only two new tool schemas: `play_music`, `music_control`.
- Duck to 25% of the current volume; restore 0.5 s after the last reason to duck ends.
- Workaround switch `APPY_MIC_HEARS_MUSIC=1`; tag every workaround code spot with the comment `HEARING-WORKAROUND(respeaker)`; utterance cap 15 s; strict triggers: whole utterance ≤ 6 words. Flag unset = today's behaviour exactly.
- Every tool failure returns `json.dumps({"error": "<one plain sentence Appy can say>"})`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Riff not running when Tudor says "pause"/"skip": friendly error ("Riff isn't open"), no launch (only `play_music` launches Riff). → test in Task 5.
2. Refresh token revoked or expired: one error telling Appy to say "run spotify-login", token file left intact. → test in Task 2.
3. Tudor changes Riff's volume by hand while ducked: restore must not overwrite it (restore only if Riff is still at the level the ducker set). → test in Task 7.
4. Appy quits or crashes while ducked: music must come back up (`Ducker.restore_now()` in `main`'s `finally`). → test in Task 7.
5. Ambiguous search ("play Hello"): plays the top track and the result names the real title and artist; zero results → "I couldn't find …" error. → test in Task 5.

### Task 7: Ducker

**Files:**
- Modify: `dj.py` (class `Ducker`), `main.py`, `tests/test_dj.py`

**Interfaces:**
- Consumes: `Riff.is_playing/volume/set_volume`, `DJ.set_volume_hook`.
- Produces: `class Ducker(riff: Riff, level: float = 0.25, restore_delay: float = 0.5, timer=threading.Timer)`:
  - `hold(reason: str)` and `release(reason: str)`, reasons `"user"` and `"appy"`.
  - The first hold while Riff `is_playing()` saves `volume()` and sets `saved * level`.
  - When the last reason is released, a restore runs after `restore_delay`; a new hold cancels it. Restore sets `saved` only if Riff's volume still equals the value the ducker set (±0.02); otherwise it leaves Riff alone.
  - `on_volume_change(v) -> bool`: while ducked, store `v` as `saved`, apply `v * level`, return True.
  - `restore_now()`.
  - Every Riff error is swallowed.
- Wiring in `main.py`:
  - `on_speech_start` → `hold("user")`; `on_speech_discarded` → `release("user")`.
  - `Speaker(on_audio=...)`: `queued`/`playing` → `hold("appy")`, `silent` → `release("appy")`, still calling `status.set_audio`.
  - After `speaker.wait()` in the turn's `finally` → `release("user")`.
  - `dj.set_volume_hook(ducker.on_volume_change)`.
  - `ducker.restore_now()` in `main`'s outer `finally` (Review Focus 4).
